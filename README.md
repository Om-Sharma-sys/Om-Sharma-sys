## 🧠 Suicide Ideation Detection using DistilBERT

- Developing an NLP-based suicide ideation classification system using transformer-based architectures and manually annotated datasets
- Using Label Studio for human annotation and dataset refinement while addressing class imbalance and limited-data overfitting challenges
- Fine-tuning DistilBERT models with batched training workflows and evaluating performance using macro and weighted F1-score metrics
- Experimenting with dataset scaling, tokenization strategies, and hyperparameter optimization to improve model generalization
